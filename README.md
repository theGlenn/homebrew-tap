# theGlenn/homebrew-tap

Homebrew formulae for [theGlenn](https://github.com/theGlenn)'s tools.

```sh
brew install theGlenn/tap/modelfs
```

| Formula | What it installs |
|---|---|
| `modelfs` | [ModelFS](https://github.com/theGlenn/modelfs): `modeld`, which keeps one copy of every local AI model on your Mac, however many apps use it |

Each project's release workflow points its formula at the new release by
rewriting the `url` and `sha256` lines.
